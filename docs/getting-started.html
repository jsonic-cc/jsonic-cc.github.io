Getting started

Drop in json.h.

Jsonic++ is header-only. Vendor include/json.h into your project and compile as C++17 or later.

#include "json.h"
#include <iostream>

int main() {
    json::Document value;
    std::string error;
    if (!json::Document::parse(R"({"name":"Jsonic++"})", value, error)) {
        std::cerr << error << "\n";
        return 1;
    }
    std::cout << value["name"].string << "\n";
}

Build the repository tests

make test
make test-sanitize

The standalone tests are only one layer. Parser changes are also synchronized into Nift and Minify++ and must pass those consumers' integration contracts.
