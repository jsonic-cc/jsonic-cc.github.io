Documentation

A small JSON component with a clear boundary.

Jsonic++ is the independent home of the JSON implementation used by Nift and Minify++. The public surface is intentionally boring: one header, one JSON value type, explicit parse errors, and ordinary C++ containers underneath.

Design goal: correct JSON parsing and useful value access without pulling a large dependency or unrelated formats into your program.

Start here

Getting started covers integration. API documents the current surface. Contracts explains the guarantees the project tries to preserve. Battle tested explains the evidence and its limits.

Where it came from

The parser was not invented for a standalone branding exercise. It was extracted from a byte-identical implementation already exercised by Nift core and Minify++. Jsonic++ now owns parser semantics independently; those projects continue to vendor synchronized copies.
