API

One value model.

json::Document represents null, boolean, number, string, array and object values. The API intentionally exposes straightforward C++ data rather than a large abstraction hierarchy.

Parse

json::Document value;
std::string error;
if (!json::Document::parse(source, value, error)) {
    // error includes line and column information
}

Inspect

if (value.is_object() && value.has("name")) {
    std::cout << value["name"].string;
}

auto &first = value["items"][0];

Serialize

std::string compact = value.dump(0);
std::string pretty  = value.dump(2);

Large named arrays

for_each_array_item can stream items from a named root-array member without constructing that entire array as one DOM. Nift uses this for large metadata files.
